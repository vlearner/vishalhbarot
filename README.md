# Vishal H Barot - Personal Website

A simple, secure personal website showcasing information about me and my certifications.

## Live Site

[https://vishalhbarot.com](https://vishalhbarot.com)

## Features

- **About Me** - Personal introduction
- **Certifications** - Professional certifications and achievements
- Simple, responsive design
- Security best practices implemented

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Security

This site implements several security measures:
- Content Security Policy (CSP)
- X-Content-Type-Options
- Strict referrer policy

## Setup

This site is hosted on GitHub Pages with a custom domain.

To run locally:
1. Clone the repository
2. Open `index.html` in a web browser
